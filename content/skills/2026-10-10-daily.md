# Skills 日报 · 2026-10-10

今日精选 5 个值得装进 agent 工具箱的 Skill（来源：Anthropic 官方库、Vercel、高质量 GitHub skill 仓库）。

## 1. frontend-design — 做出不像模板的前端 UI

**介绍**  
Anthropic 官方 skill：强迫 agent 先做设计计划（色彩 token、字体角色、布局与「签名元素」），再对照「会不会长得像默认奶油底+衬线」做修订，最后才写代码。专治 AI 味千篇一律的落地页与后台。

**用法**  
源码：[anthropics/skills → frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)  
在 Claude Code / 兼容 Agent Skills 的工具中安装官方 skills 后，做新 UI 或大改版时触发；也可把 `SKILL.md` 拷进项目 `.cursor/skills/` / `.agents/skills/`。

**应用场景**  
营销站、仪表盘、产品壳子视觉改版；团队希望 agent 先出设计 token 再实现。

**推荐学习程度**：入门

## 2. skill-creator — 会写、会测、会迭代 Skill 本身

**介绍**  
官方「造 skill 的 skill」：从零写 SKILL.md、改描述触发精度、跑 eval、做 A/B 与 benchmark、用 grader/comparator 代理打分。把「重复粘贴同一段提示」升级成可版本化资产。

**用法**  
源码：[anthropics/skills → skill-creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator)  
安装后用 `/skill-creator`（或等价触发）生成/改进 skill；按仓库内 `scripts` 与 `references/schemas.md` 跑聚合 benchmark 与 eval viewer。

**应用场景**  
第二次想粘贴同一套流程时；团队要把领域 runbook 固化成可跨 Cursor/Claude Code 复用的 skill。

**推荐学习程度**：进阶

## 3. webapp-testing — Playwright 本地验 UI

**介绍**  
官方 webapp-testing skill：用 Playwright 验证本地 Web 应用（截图、浏览器日志、服务启停）。适合让 agent「写完再自己点一遍」，而不是只声称可用。

**用法**  
源码：[anthropics/skills → webapp-testing](https://github.com/anthropics/skills/tree/main/skills/webapp-testing)  
典型模式：`python scripts/with_server.py --server "npm run dev" --port 5173 -- python your_automation.py`，由 helper 起服务、等端口、跑脚本再清理。

**应用场景**  
前端回归、表单/路由冒烟、修 bug 后的复现验证、CI 前的本地验收。

**推荐学习程度**：进阶

---

## 4. vercel-react-best-practices — Vercel 工程向的 React/Next 性能规则

**介绍**  
Vercel 官方 agent-skills 中的性能 skill：数十条按影响分级的规则（消除 waterfall、砍包体、服务端/客户端取数、重渲染等），带正反例，专门喂给 coding agent 写/审 React 与 Next.js。

**用法**  
源码：[vercel-labs/agent-skills → react-best-practices](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices)  
安装：`npx skills add vercel-labs/agent-skills --skill vercel-react-best-practices`  
完整规则见同目录 `AGENTS.md`；对组件或页面说「按 Vercel 性能规则 review」即可触发。

**应用场景**  
Next.js App Router 性能债、首屏与瀑布流、bundle 瘦身、PR 前性能审查。

**推荐学习程度**：进阶

---

## 5. obra/superpowers — 可组合的工程方法论 Skill 集

**介绍**  
高星 agentic skills 框架：把 brainstorm → 写计划 → TDD/执行 → 调试/评审拆成可组合 skill，并强调计划能跨会话存活。适合「多文件功能别指望一轮聊完」的工作方式。

**用法**  
仓库：[github.com/obra/superpowers](https://github.com/obra/superpowers)  
Claude Code：`/plugin marketplace add obra/superpowers-marketplace` 后 `/plugin install superpowers@superpowers-marketplace`（或以官方插件市场安装说明为准）；新开会话后可用 `/superpowers:brainstorm`、`write-plan`、`execute-plan` 等流程。

**应用场景**  
跨多文件的功能开发与重构、需要书面计划再动手的任务、想给 agent 一套稳定工程节奏。

**推荐学习程度**：深度

# 2026-11-10 Skills 日报

今日两条：Jane Street 的苏格拉底家教技能，以及面向界面质量的 Interfaces 技能包。

## 1. janestreet/agent_skills — Jane Street 公开的 Agent Skills（首发 socratic-tutor）

**介绍**  
Jane Street 公开的 agent skills 仓：每个技能一个目录加 `SKILL.md`。目前第一支是 **socratic-tutor**——把模型收成严格的私人导师：先诊断，再给出 0–5 级技能图，一次只问一个问题，带间隔复习和期末评估。MIT。约 2.2k★（2026-11-03 新建）。

**用法**  
仓库：[github.com/janestreet/agent_skills](https://github.com/janestreet/agent_skills)。skills.sh：[skills.sh/janestreet/agent_skills](https://www.skills.sh/janestreet/agent_skills)。

```bash
npx skills add janestreet/agent_skills
# 或把 socratic-tutor 目录拷进 agent 的 skills 文件夹
# 普通聊天机器人：把 SKILL.md 正文贴进自定义/系统提示，再说「教我 X」
```

**应用场景**  
准备补线性代数：导师先摸底，再按技能图一次只问一题，错了间隔再问，最后做一次评估。

![socratic-tutor 应用场景示意](./assets/2026-11-10/socratic-tutor.png)

**推荐学习程度**：入门

## 2. jakubkrehel/skills — 把界面做得更好的一组 Agent Skills

**介绍**  
Jakub Krehel（[interfaces.dev](https://interfaces.dev/)）的界面技能包：覆盖无障碍、版式、字体、色彩、文案与 UI 打磨。例如 `better-interface` 出一份分项排序的审查报告，`interface-review` 专门审分支/PR 引入的界面回归，还有 typography / colors / accessibility / layout / writing，以及 `break`、`state-machine`、`build-design` 等。MIT。约 11.9k★。

**用法**  
仓库：[github.com/jakubkrehel/skills](https://github.com/jakubkrehel/skills)。skills.sh：[skills.sh/jakubkrehel/skills](https://skills.sh/jakubkrehel/skills)。

```bash
npx skills add jakubkrehel/skills
# Claude Code 插件：
# /plugin marketplace add jakubkrehel/skills
# /plugin install interfaces@interfaces
```

**应用场景**  
设置页 PR 开来：agent 按无障碍、对比度、文案和间距出一份排序报告，再改一版再审。

![interfaces-skills 应用场景示意](./assets/2026-11-10/interfaces-skills.png)

**推荐学习程度**：入门

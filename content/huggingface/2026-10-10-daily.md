# Hugging Face 日报 · 2026-10-10

今日精选 4 个本周前后可立刻试的模型 / 数据集 / Space（宁缺毋滥）。

## 1. LightOnOCR-3 — 轻量 OCR + 版面 Grounding 一体

**介绍**  
LightOn 于 10/8 发布的 OCR 家族（0.8B / 1B / 4B，Apache 2.0）：空 prompt 做转写；`grounding` 模式额外输出带标签的框、图注与图表数据表。小参数量在 olmOCR / ParseBench 上接近甚至超过更大模型，适合替换复杂文档流水线。

**用法**  
模型：[LightOnOCR-3-0.8B](https://huggingface.co/lightonai/LightOnOCR-3-0.8B) · [1B](https://huggingface.co/lightonai/LightOnOCR-3-1B) · [4B](https://huggingface.co/lightonai/LightOnOCR-3-4B)  
Demo：[LightOnOCR-3-Demo](https://huggingface.co/spaces/lightonai/LightOnOCR-3-Demo)  
博文：[LightOnOCR-3](https://huggingface.co/blog/lightonai/lightonocr-3)  
本地用 transformers/vLLM 加载后，先空 prompt 看转写，再发 `grounding` 看框与图表 HTML。

**应用场景**  
RAG 前文档解析、扫描件/多栏 PDF、需要框选区域或抽图表数值、想在边缘算力上跑 OCR。

**推荐学习程度**：进阶

## 2. Carbon-A-1.2B — 跨物种 DNA 基因区预测 + CADB

**介绍**  
HuggingFaceBio 10/8 发布：1.2B 参数、约 98K bp 上下文，直接从 DNA 预测蛋白编码区（双链、核苷酸分辨率），并在 GenBank 规模跑出 Carbon Annotation Database（约 566M 候选位点）。对生物信息与「开放生物模型」方向都很有信号。

**用法**  
模型：[HuggingFaceBio/Carbon-A-1.2B](https://huggingface.co/HuggingFaceBio/Carbon-A-1.2B)  
Space：[CADB Explorer](https://huggingface.co/spaces/HuggingFaceBio/genbank-annotation-explorer)  
博文：[Carbon-A](https://huggingface.co/blog/HuggingFaceBio/carbon-annotator-genbank-genome-annotation)  
先在 Space 翻已有注释；自有组装再按模型卡跑推理，并用置信度过滤位点。

**应用场景**  
非模式生物基因组注释、补 RefSeq 缺口、对比传统 gene finder，或做 CADB 下游蛋白挖掘。

**推荐学习程度**：深度

## 3. Falcon-ASR Demo — 阿语（含阿联酋方言）优先的多语 ASR

**介绍**  
TII 10/7 介绍的 1.6B 语音识别：强调阿拉伯语（尤其 Emirati），同权重也支持英/法/西/葡，带词级时间戳；公开评测上阿语平均 WER 优于当时榜单快照头部结果。当前最稳妥的上手方式是官方 Demo Space。

**用法**  
Space：[tiiuae/falcon-asr-demo](https://huggingface.co/spaces/tiiuae/falcon-asr-demo)  
博文：[Introducing Falcon ASR](https://huggingface.co/blog/tiiuae/falcon-asr)  
上传或录制音频即可转写；对比方言口语与电话场景效果。API / 原生应用仍在规划。

**应用场景**  
阿语/海湾方言会议纪要、多语客服质检、需要词级对齐的字幕与检索。

**推荐学习程度**：入门

## 4. Exgentic/agent-llm-traces-v2 — 1 万条真实 Agent 运行轨迹

**介绍**  
10/4 发布：约 10K agent run、242K 次模型调用，统一成 OpenTelemetry GenAI 格式；覆盖 SWE、深度研究、AppWorld、客服等任务，以及多种 agent 设计与前沿模型。用来研究「agent 怎么走完任务」，而不只看分数。

**用法**  
数据集：[Exgentic/agent-llm-traces-v2](https://huggingface.co/datasets/Exgentic/agent-llm-traces-v2)（完整语料另有 [traces-v2](https://huggingface.co/datasets/Exgentic/traces-v2)）  
博文：[What Agents Do](https://huggingface.co/blog/michalshmu/exgentic-agent-llm-traces-v2)  
用 `datasets` 加载后按 benchmark / model / agent design 切片；可配合 [inference-perf](https://github.com/kubernetes-sigs/inference-perf) 做真实 agent 负载回放。

**应用场景**  
调试自家 agent、训/微调工具调用策略、评测推理服务在 agent 链式负载下的缓存与延迟。

**推荐学习程度**：进阶

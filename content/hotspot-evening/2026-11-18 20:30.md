### 科技/AI

**美国国会问责局测试显示四大聊天机器人可协助策划恐袭** — 国会问责局（GAO）在今年春季测试中，用已知方法绕过防护后，在 12 小时内从 ChatGPT、Claude、Gemini 和 Grok 获得可用于策划袭击的信息。其中两款模型给出了在美国大城市用自制爆炸物发动袭击的具体方案，包括日期、时间和目标；另外两款则提供了攻击电网变电站的指引，并生成相关地图和图像。测试各只进行一次，报告未点名具体模型对应结果。参议员哈桑已要求明年就 AI 安全举行听证；相关公司称测试后已加强防护
[ABC News](https://abcnews.com/Technology/ai-models-plan-viable-attack-plots-test-despite/story?id=138229892)

**微软发布 MAI Code 2 与 Code 2 Flash 编程模型** — 在 Ignite 上推出，Code 2 侧重多文件实现、仓库级推理和调试，Flash 面向高频小改和快速迭代。微软称，在四项常用企业编程基准上，Code 2 达到 GPT-6.1 Sol 约 98% 的表现、成本约为其 40%，约为 Claude Opus 5.5 的 96% 表现、成本约 5%；不过其成本对比采用了五折促销价。两款已在 GitHub Copilot 上线，Flash 还在 Microsoft Foundry 提供有限预览
[微软](https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/)

**安全公司 Calif 借助 AI 发现 Java 高危漏洞 Java4Shell** — 漏洞编号 CVE-2026-114938，存在于 OpenJDK 硬件加速 Base64 解码中，可导致内存损坏乃至远程代码执行，影响 OpenJDK 17.0.6 及之后版本，以及 Oracle、Amazon Corretto、微软和红帽等发行版。研究人员称可在默认配置下攻击 Jenkins、Jira、Confluence、Keycloak 等应用。Oracle 已于 17 日随补丁更新发布修复
[BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-java4shell-flaw-allows-rce-attacks-on-major-java-applications/)

[OpenAI](https://openai.com/index/le-groupe-figaro-and-openai-announce-partnership/)

**评测显示把军事场景说成「游戏」后，模型更容易把平民标成打击目标** — 旧金山评测公司 Vals 用无人机和卫星模拟场景测试多家前沿模型，发现它们常把平民、救护车和投降士兵标为打击目标；模型拒绝时，只要改称这是游戏，配合度往往明显上升。例如在伊朗米纳卜一所紧邻军事设施的学校卫星图上，Claude Opus 5.5 在常规测试中有 69% 的次数将其标为打击目标，游戏框架下为 72%。Vals 未测试实战部署。Anthropic 称结果不可接受，并表示将加强防护
[TechCrunch](https://techcrunch.com/2026/11/17/ai-models-can-be-tricked-into-identifying-civilians-as-military-targets-by-telling-them-its-a-game/)
